# Employee Cybersecurity Hygiene Checklist

### 1. Password Management
- [ ] Use multi-factor authentication (MFA) on all primary accounts.
- [ ] Passwords must be at least 14 characters long and complex.
- [ ] Do not reuse credentials across personal and corporate systems.

### 2. Phishing Prevention
- [ ] Verify sender email address details before clicking links.
- [ ] Hover over URLs to check target destinations.
- [ ] Do not open unexpected or unsolicited email attachments.

### 3. Device & Data Security
- [ ] Lock workstation screen when leaving the desk (`Win + L`).
- [ ] Keep operating system and third-party software updated.
- [ ] Store sensitive work files only on approved encrypted cloud drives.
